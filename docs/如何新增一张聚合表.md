# 如何新增一张聚合表（给非开发同学）

适用场景：底表里**已经有某一列**（例如「主题」），想按这一列做汇总，并导出到 Excel /（可选）送给 AI。

> 不需要写 Python。系统会用已经写好的通用汇总引擎（按列分组 → 求和 → 算增量/增速 → 可选排名与 TOP 产品）。

上手总览请先看 [`同事上手清单.md`](同事上手清单.md) 与根目录 `README.md`。

---

## 三步操作

1. 打开项目里的 `configs/聚合登记表.xlsx`
2. **不要改**前四行「是否内置 = 是」的表（area / track / manager / national_team）
3. 在表格最下方**新加一行**，按下面对照填写，保存后**重启** Web 或再点「一键分析」

在网页「概览 → 已加载聚合」里应能看到你的新代号。若列表仍只有旧四表，看文末「常见错误」。

---

## 填写对照

| 列名 | 怎么填 | 例子 |
|------|--------|------|
| 代号 | 英文唯一名，字母开头 | `theme` |
| 中文表名 | 导出 Excel 的工作表名 | `主题ETF汇总` |
| 说明 | 一句话说明用途 | `按主题汇总规模` |
| 分组列 | 底表真实列名（必须已存在） | `主题` |
| 输出列名 | 结果表里这一列叫什么 | `主题类型` |
| 是否排名 | 是 / 否 | `否` |
| 是否TOP产品 | 是 / 否 | `是` |
| TOP数量 | 正整数，默认 3 | `3` |
| 默认启用 | 是=一键分析自动算 | `是` |
| 送给AI | 是=报告模型能看到 | `是` |
| AI标题 | 送给 AI 时的标题 | `主题ETF聚合数据` |
| AI顺序 | 数字，越大越靠后；新表建议 ≥50 | `50` |
| 报告章节 | `区域` / `赛道` / `管理人` / `目标公司` | `赛道` |
| 是否内置 | **新表必须填「否」** | `否` |

## 计算是怎么发生的？（无需你写代码）

```text
你在登记表填的「分组列 / 是否TOP / 是否排名」
        ↓
系统转成内部规格 AggregationSpec
        ↓
调用已有函数 calc_aggregation（与区域、赛道同一套逻辑）
        ↓
得到新聚合表 → 写入汇总 Excel；（若送给AI=是）进入报告
```

旧的四张内置表算法**不会因为你加新行而改变**。登记表损坏时，系统会回退到代码内置四表，保证旧流程仍能跑。

---

## 什么情况必须找开发？

- 底表还没有你想分组的那一列（要先改底表 / `scripts/contracts/base_table.py`）
- 不是「按一列汇总」，而是要筛选某公司、多表拼接、特殊公式（例如目标公司切片）

这类需求在 `scripts/calculations/` 由开发实现，不通过本登记表自助完成。

若还要改 AI「怎么写这段分析」，需同步改 `skills.md`（必要时 `skill_check.md`）。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 网页看不到新表 | 未保存 / 未重启 / 默认启用=否 | 保存、重启 Web、改「是」 |
| 报错缺分组字段 | 分组列名与底表不一致 | 打开底表核对表头（含空格/全角） |
| 一键分析仍只有旧四表 | 登记表损坏，系统回退内置 | 从 Git 还原 `configs/聚合登记表.xlsx`，勿改坏表头列名 |
| 改了内置四行没生效 | 内置计算参数以代码为准 | 请勿改内置四行；只许新增行 |
| AI 没用上新表 | 「送给AI」=否 或 skills 未写任务 | 改为「是」，并在 skills.md 补一句分析要求 |

## 给开发的补充

- 加载入口：`scripts/contracts/table_plugins.py`
- 重新生成默认登记表：`python -c "from scripts.contracts import write_registry_excel; print(write_registry_excel())"`
- 对照测试：`python -m scripts.tests.test_agg_parity`
- 厂商预设：`scripts/providers.py` + `.env` 的 `ETF_AI_API_TYPE`
