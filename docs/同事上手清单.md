# 同事上手清单（打印页）

把下面勾完，就能独立跑通一次分析。

## 环境

- [ ] 已 `git clone` 或拿到本仓库最新代码  
- [ ] `python -m venv .venv` 且已 `source .venv/bin/activate`  
- [ ] `pip install -r requirements.txt` 成功  
- [ ] `cp .env.example .env`，填入 `ETF_AI_API_KEY`（及正确的 `ETF_AI_API_TYPE` / `ETF_AI_MODEL_NAME`）  
- [ ] **确认没有把 `.env` 提交到 Git**

## 数据

- [ ] 底表 Excel 已放到 `data/etf底表.xlsx`，或准备在 Web 上传  
- [ ] Sheet 名与 `scripts/contracts/meta.py` 中 `sheet_name` 一致（不一致就改契约）  

## 跑通

- [ ] `streamlit run web.py` 能打开页面  
- [ ] 点「一键分析」能出 Excel（无 Key 也应能出表）  
- [ ] 有 Key 时能出 AI 报告 + 审核分；进度能看到阶段 3 的子步骤  
- [ ] 「概览 → 已加载聚合」能看到 area / track / manager / national_team  

## 扩展（按需）

- [ ] 读过 [`如何新增一张聚合表.md`](如何新增一张聚合表.md)  
- [ ] 知道：**勿改登记表内置四行**；复杂切片找开发改 `scripts/calculations/`  

## 出问题先看

1. README「常见问题」  
2. 本次运行的 `runs/{run_id}/run_manifest.json`  
3. `prompts/` 与 `ai/` 目录里的原始请求/响应  

仓库说明与命令细节以根目录 [`README.md`](../README.md) 为准。
